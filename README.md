# fucketf

ETF 预测模型 v4 — 资金行为、拥挤与撤退识别 + 规则模型 + 计量诊断。

## 数据源
- ETF 行情：优先 AkShare/东方财富前复权，失败回退腾讯财经 API（`qfq`）
- ETF 份额：上交所历史份额快照 + 深交所最新份额快照；份额信号先进入计量诊断，不直接参与交易评分
- 四大报：同花顺 https://stock.10jqka.com.cn/bktt_list/
- 融资融券：东方财富公开数据接口
- 外部情绪：证监会、工信部、国家统计局、深交所公开页面（无需 API Key）

## 运行方式

先用 `python3 daily_pipeline.py --dry-run` 完整模拟数据更新、模型计算和研报看板生成；该模式不会提交或推送 Git。确认输出无误后，再运行不带参数的生产流水线。

看板采用研究简报风格：结论优先、证据分层、回测单列、风险提示明确；不把计量模型的样本内结果直接当作交易建议。

## v4 核心方向

目标不是只追逐已经上涨的 ETF，而是识别：

1. 资金与价格是否开始加速（`early_entry`）
2. 趋势、成交和波动是否已经拥挤（`crowding`）
3. 拥挤后是否出现动量衰减和放量下跌（`withdrawal_risk`）

当前行情源没有 ETF 份额和净申赎字段，因此 `flow_proxy` 明确是基于价格加速度与异常成交量的代理变量，不等同于真实资金净流入。模型另外输出 `news_price_gap`（新闻信号相对价格动量）和 `news_flow_gap`（新闻信号相对成交量/换手代理）；后者不是 ETF 份额变化，待接入份额数据后再替换为真实申赎预期差。

ETF 池从 11 只扩至 27 只，每个宽基、风格、行业、跨境和防守类别保留少量高流动性代表。同类产品通过 `group` 限制，组合不会同时买入多只高度同质 ETF。

市场状态分为 `risk_on / neutral / stress`，用于动态切换趋势与均值回归权重，并控制总风险预算。Logit/OLS 只承担诊断；当样本外准确率没有超过简单基准时，不作为顶部交易推荐来源。

## 新闻扩展原则

四大报信号增加了“新闻新颖度”，重复叙事不会和首次出现的主题获得相同权重。后续扩展外部新闻时按以下顺序：

1. 官方政策与交易所公告；
2. 行业/主题相关新闻；
3. 宏观市场新闻；
4. 搜索与社交热度仅作为拥挤度，不直接决定买卖。

`fetch_external_news.py` 每日抓取上述公开页面，保存标题、来源、类别、发布时间和原文链接到 `data/external_news.json`。抓取失败只影响该来源，不阻断主模型；标题超过 30 天自动清理。

外部情绪分由政策/监管、行业和宏观三类标题构成，并按 ETF 关键词映射到板块。当前仍是可解释的关键词事件分，不是大模型语义判断；后续只有在积累足够历史标签后，才考虑中文金融文本模型。

参考 GitHub 成熟项目的经验，新闻必须有发布时间硬过滤、相关度分层、缓存、失败降级和多源回退；不把单一爬虫或大模型输出当作确定性信号。

## 模型架构（三层）

### 第一层 · 报纸情绪评判
四大证券报标题 → 看涨/看跌关键词计数 → 情绪分 → 板块热点排名
- 情绪分 = (看涨次数 - 看跌次数) / (总信号 + 1)
- 26个看涨关键词 + 26个看跌关键词
- 板块匹配：标题关键词 → ETF板块
- 情绪信号在模型中享有 **3倍权重**

### 第二层 · 规则模型
五信号加权评分，选前3只ETF：
```
总分 = 3×S(情绪) + M(动量) + V(量比) + R(均值回归) + E(经验)
```
- 防偷看设计：价格类信号用前一日数据，情绪用当日报纸，收益=当日日内

### 第三层 · 计量交叉验证
- **Logit 回归**：预测涨跌方向 P(涨) 和概率
- **OLS 回归**：预测收益率 + 因子显著性检验
- **Lasso**：变量选择，剔除无效因子
- 看好板块：P(涨)最高的3个ETF + 建议文字
- 看空预警：P(跌)最高的3个ETF + 建议文字

## 每日流水线 (daily_pipeline.py)
1. 增量更新 ETF 行情 → data/etf_history.json
2. 抓取四大报 → data/newspapers.json
3. 运行规则模型 → data/model_results.json
4. 运行计量模型 → data/econometric_results.json
5. 生成看板 → etf-dashboard/dashboard.html

## 运行
```bash
pip install -r requirements.txt
python3 daily_pipeline.py
```
